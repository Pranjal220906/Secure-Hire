# SecureHire 🛡️

**India's #1 Verified Bodyguard Booking Platform**

SecureHire is a modern, responsive web platform that allows individuals, corporates, VIPs, celebrities, and politicians to book verified, background-checked security personnel instantly — across 120+ cities in India.

## 🌟 Features

- 🔍 **Search & Filter** — Find guards by city, category, or name
- 🗂️ **12 Service Categories** — VIP Protection, Event Security, Corporate, Residential, Travel, Election & Political, Celebrity & Film, Female Guard, Medical Escort, Night Security, Close Protection & Driver, and Personal Guard
- 👮 **Featured Guards** — Browse verified professionals with ratings, experience, location & pricing
- ⭐ **Ratings & Reviews** — Real client testimonials and star ratings
- 🛠️ **How It Works** — Simple 4-step booking process
- ✅ **Trust Signals** — Ex-military & police guards, live tracking, secure payments
- 📱 **Fully Responsive** — Mobile-first design, works on all screen sizes
- 🚀 **Vercel Ready** — Single `index.html`, deploy in one click

## 🎨 Tech Stack

- Pure HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Syne + DM Sans)
- No frameworks or dependencies — zero build step required

## 🚀 Deploy on Vercel

1. Fork or clone this repo
2. Go to [vercel.com](https://vercel.com) → New Project
3. Import the repo → Click **Deploy**
4. Done ✅
